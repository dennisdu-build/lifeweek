# LifeWeek · 人生周历

一个纯前端的人生周历可视化工具，基于 HTML + Tailwind CSS，打开即用。

## 页面

| 文件 | 说明 |
|---|---|
| `life.html` | 人生周历主页面 |
| `auto-mark-calendar.html` | 自动标记前置周数日历 |

## 使用方法

直接用浏览器打开任意 HTML 文件即可，无需构建、无需安装依赖。

## 技术栈

- 原生 HTML / CSS / JavaScript
- [Tailwind CSS](https://tailwindcss.com/)（CDN 引入）
- [Font Awesome](https://fontawesome.com/)（CDN 引入）
